📖 How to Play

1

The number on the red-circled tile shows 1 mine nearby. You can mark a suspected mine's location with a flag.

2

If you're not sure where a mine is, mark it with a question mark. Using the yellow-circled tile as a reference, you can work out which tile is mine-free (the green-circled tile).

3

Once you've figured out whether a question-marked tile is a mine, you can either flag it or open it.

🧱 Wall Mode

When Wall Mode is on, wall tiles appear at random positions, just like mines. Wall tiles are visibly stone-textured from the start and are treated as already-opened tiles. However, they show no number, so you can't tell if a mine is nearby.

💎 Treasure Hunt Mode

When Treasure Hunt Mode is on, treasure tiles are hidden at random positions, just like mines. It can be combined with Wall Mode.

Unlike mines, treasure tiles count as -1, and instead of avoiding them like mines, you must open them.

Even if a mine and a treasure next to the same tile cancel out to 0, that tile is not treated as blank — the number "0" is still shown. (Unlike a real blank tile, it won't auto-open its neighbors, so stay careful)

Once every treasure tile has been found and opened, the game is cleared immediately, regardless of any remaining normal tiles.
